ESP32 :: FIRMWARE FLASHER

Flashes compiled .bin firmware to an ESP32 over USB, right from this page (Web Serial API).
Your browser doesn't support the Web Serial API. This tool needs Chrome, Edge, or another Chromium-based browser (desktop).
This page is open as a local file (), and Chrome/Edge block the module script this page needs when opened that way — that's why clicking Connect does nothing. Fix: open a terminal in this file's folder and run python3 -m http.server 8000, then open http://localhost:8000/esp32_flasher.html in your browser instead.

Plug your ESP32 in via USB, click connect, and pick its serial port from the browser's device list. Put the board in bootloader mode first if it doesn't auto-reset (hold BOOT, tap EN/RESET, release BOOT — varies by board).

2 · Firmware file(s)

Quick-fill for this chip:
Compile your sketch first (Arduino IDE: Sketch → Export Compiled Binary, or PlatformIO: pio run) to get a .bin file — this page flashes binaries, it doesn't compile source. This page accepts any file, any chip — after connecting, it detects your specific ESP32 variant and the quick-fill buttons above set the correct bootloader offset for that chip (offsets differ between variants). If your IDE exports a merged/full image (bootloader+partitions+app in one file), use address 0x0 regardless of chip. Connect a device to enable chip-specific quick-fill.
