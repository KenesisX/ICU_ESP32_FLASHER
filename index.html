Raspberry Pi Image

Complete turnkey deployment for Raspberry Pi 4/5. Full backend stack pre-configured with all services.

  • Node.js API + Express gateway
  • Python FastAPI backend
  • PostgreSQL + Redis
  • RTL-SDR support
  • Auto-start services

Installation

  1. Download image file
  2. Write to microSD card: sudo dd if=icu-pi.img of=/dev/sdX bs=4M
  3. Insert into Raspberry Pi
  4. Power on (wait ~2 minutes for first boot)
  5. Access: http://raspberrypi.local:5000

ESP32 Firmware

SDR sensor module & I2S audio capture. WebSocket connection to ICU platform.

  • 3-channel frequency tracking
  • I2S audio/RF capture
  • WiFi + WebSocket
  • RSSI monitoring
  • Temperature sensor

Installation

  1. Install esptool.py: pip install esptool
  2. Connect ESP32 to USB
  3. Flash: esptool.py -p /dev/ttyUSB0 write_flash 0x1000 esp32-firmware.bin
  4. Configure WiFi in serial monitor
  5. Connect to ICU platform

Quick Start Guides

Before you install: binaries are produced by the CI workflow in .github/workflows/build.yml. Verify the checksum on the release page.

Beginner (Phone Only)

  1. Download APK to Android phone
  2. Install via file manager
  3. Launch app
  4. Connect to ICU Pi
  5. Monitor sensors in real-time

Intermediate (Raspberry Pi)

  1. Download the Pi image from the release page
  2. Write to microSD card
  3. Insert into Pi 4/5
  4. Power on (2 min boot)
  5. Access via http://raspberrypi.local:5000

Advanced (Full Stack)

  1. Deploy Raspberry Pi image
  2. Flash ESP32 with firmware
  3. Install Android APK
  4. Configure WiFi & APIs
  5. Integrate RTL-SDR device
